Admin. Base de Datos

¿Que es exactamente un Admin. de Base de Datos?

La Administracion de Base de Datos es aquella tarea sobre la gestion y mantenimiento del software de todos los sistemas de gestion de bases de datos y cosas relacionadas al software.

Tipos de Administradores de Bases de Datos

1. Admin.Base de Datos de Sistemas: Son las que se encargan de tener bien organizados los aspectos fisicos de la administracion de bases de datos, como por ejemplo la configuracion, las actualizaciones, las copias de seguridad, la instalacion, restauraciones, mantenimiento, recuperacion ante problemas del DBMS, etc.

2. Admin.Base de datos de Desarrollo: Estos son los que se fijan en los aspectos logicos y de desarrollo de la administracion de bases de datos, como lo son el diseño y el mantenimiento del modelo de datos, la escritura y optimizacion de SQL, la codificacion de procedimientos almacenados, la colaboracion con los desarrolladores para ayudar a la eleccion de caracteristicas y/o funcionalidades del DBMS, etc.

3. Admin.Base de Datos de Aplicaciones: Estan siempre en organizaciones que tienen software de terceros, como por ejemplo los sistemas CRM (Gestion de Relaciones con el Cliente). Actuan como enlaces entre diversos sistemas de gestion de bases de datos (DBMS), y tambien se encargan de que la aplicacion este optimizada para la base de datos, y del buen funcionamiento de los componentes de las aplicaciones en general. Esto lo hacen para que se puedan realizar las actividades que los componentes llevan a cabo, como por ejemplo las actualizaciones de aplicaciones, la clonacion de bases de datos, la creacion, y la ejecucion de rutinas de limpieza de datos, la gestion del proceso de carga de datos, etc.

Responsabilidades de un Admin. de Base de Datos

Las responsabilidades específicas de un administrador de bases de datos varían en función del tamaño y las necesidades de la organización para la que trabaja. Sin embargo, la mayoría de sus tareas incluirán desarrollar y mantener bases de datos, garantizar la seguridad de los mismos, ajustar el rendimiento, realizar copias de seguridad de los datos y proporcionar formación y soporte a los usuarios. Los DBA también pueden encargarse de diseñar bases de datos y supervisar su construcción en grandes organizaciones.

Herramientas

El Admin.Base de Datos cuenta con algunas herramientas, las cuales sirven para ayudar al usuario a gestionar todo esto de forma casi general:

1. Microsoft SQL Server: Ofrece herramientas con interfaz grafica de usuario para que los usuarios puedan, crear, administrar, y manipular datos mediante el uso del lenguaje de consulta Transact-SQL.

2. PostgreSQL: Este es un sistema de gestion de base de datos de codigo abierto, lo que significa que es gratuito, y cuenta con buena flexibilidad e intenta salvarte de costos. Se lo define como relacional y no relacional ya que admite tanto los datos estructurados (que son los relacionales), y los no estructurados (los que no son relacionales), y esto lo convierte en versatil.

3. MongoDB: Es otra Base de Datos de codigo abierto, que se encarga del almacenamiento de datos dentro de documentos flexibles, como los JSON (), en tablas y filas tradicionales. Desarrollando un poco mas lo de la flexibilidad, quiere decir que no necesariamente se necesita un esquema predefinido, ya que los campos pueden añadirse o eliminarse de los documentos cuando sea necesario y sin ningun problema.

4. MySQL: Este tambien es un sistema de gestion de base de datos relacionales y de codigo abierto, encargado tambien de almacenar datos en tablas bien organizadas en filas y columnas, con ayuda del lenguaje SQL, que esta a disposicion para realizar consultas y manipular la informacion. Otros datos interesantes e importantes, son que este sistema es rapido, con utilidad facil, confiable, y estable. Este sistema se utiliza en aplicaciones web, redes sociales, etc.
